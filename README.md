# Padhow for macOS

Write and revise across your Mac with a keyboard-first writing assistant.

## Get Padhow

[Download the latest release](https://github.com/ctwhome/padhow-releases/releases/latest)

Choose `Padhow-VERSION-macos-arm64.dmg`, open it, and drag Padhow into Applications.
Releases target Apple Silicon Macs (M-series), macOS 12 or later. Apple's
on-device Foundation Models integration requires macOS 26 and supported hardware.
The download link becomes available when the first release is published.

Updater-enabled builds check for releases and download updates in the background.
Choose **Restart and update** when you're ready. Builds without an updater need
one manual installation of an updater-enabled release.

Issues are public. Remove API keys, personal documents, and other private
information from screenshots and logs before posting.

This repository hosts official downloads and public issue tracking. Application
source code is maintained privately. Public downloads do not grant an open-source
license; Padhow remains proprietary.
